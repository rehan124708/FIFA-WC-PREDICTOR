# FIFA-WC-PREDICTOR
Built a full FIFA World Cup 2026 tournament simulator in Python using Tkinter, covering all 48 qualified nations from group stage draws through the knockout rounds to the Final. Includes automated fixture generation, live standings, bracket progression, penalty shoot-out logic for tied matches, and team-specific color-coded UI theming.

A fully functional desktop tournament simulator built in Python using Tkinter, recreating the complete FIFA World Cup 2026 experience — from the group stage draw through to the Final.
Features:

Full 48-team tournament structure matching the expanded 2026 format
Automated group stage simulation with standings and progression logic
Complete knockout bracket (Round of 32 through Final)
Penalty shoot-out simulation for drawn knockout matches
Team-specific color theming for a visually distinct UI experience
Built entirely with core Python and Tkinter — no external game engines

Tech stack: Python, Tkinter
What I learned: Working through tournament bracket logic, state transitions between match rounds, and building a responsive GUI from scratch without a framework.
